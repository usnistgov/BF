# <l style="color: #6366f1">BF Process <br/> _`Irena Bojanova, Inventor/Creator, PI & Lead, NIST Bugs Framework (BF), 2014 – ~~~`_</l>

The BF Processes are presented on Figure 1.

{{< img src="images/BF Processes/BF Processes.svg" caption="Figure 1. Bugs Framework (BF) Processes for the BF Taxonomy Creation and BF Vulnerability Specifications Creation" >}}

The BF processes are the BF Taxonomy Creation (see the branch that starts with the Define/Refine BF Taxonomy Structure block on Figure 1) and the BF Vulnerability Specifications Creation (see the branch that starts with the Define/Refine BF Specification Structures block on Figure 1). The former includes the creation of the BF Bugs models. Both require the definition of BF Operation, Weakness, Vulnerability, and Security Concepts models. The latter also requires the creation of the BF Vulnerability State model and the BF Vulnerability Specification model (see the white and purple blocks at the top of Figure 1). 
 
The process of BF Taxonomy Creation defines the steps for the creation of the BF Taxonomy of security bugs and related faults as causes for the operations of distinct execution phases over their operands to result in errors and final errors as consequences; and the steps for the creation of BF Bugs Models, BF Semantic Matrices and Graphs, BF Class Taxonomies, and BF Formal Language. 

The process of BF Vulnerability Specifications Creation defines the steps for the analysis of vulnerable code and vulnerability descriptions, identification of security weaknesses, and the creation of BF vulnerability specifications as chains of formal BF weakness specifications.
